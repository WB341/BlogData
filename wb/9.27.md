# 结构、联合、枚举

## 1. 结构体 struct

- 结构体用于把不同类型的数据组合在一起。
- 它相当于一个“自定义数据类型”。
- 适合表示一个学生、员工、订单等对象。

```cpp
#include <ctime>
#include <iostream>
using namespace std;

// 结构体定义：表示学生信息
struct Student {
    char name[100];     // 学生姓名
    char id[10];        // 学号
    short gender;       // 性别：0=女，1=男
    time_t birthday;    // 出生时间，来自 <ctime>
};

int main() {
    // 方式 1：先定义结构体类型，再声明变量
    Student student1 = {"Tom", "001", 1, 1234567890};

    // 方式 2：直接声明一个结构体变量并初始化
    Student student2 = {"Jerry", "002", 0, 0};

    // 方式 3：全部清零初始化
    Student student3 = {};

    cout << student1.name << " " << student1.id << endl;
    return 0;
}
```

### 说明

- `struct Student { ... };` 是结构体定义。
- `Student student1 = {...};` 是结构体变量初始化。
- `Student student3 = {};` 表示把所有成员初始化为 0 / 空字符串。
- `time_t` 需要包含 `<ctime>`。
- 结构体中的成员默认是按声明顺序连续存放的。

## 2. 结构体声明方式

### 方式 A：先定义，再声明

```cpp
struct Student {
    char name[100];
    char id[10];
    short gender;
};

Student s1;   // 声明变量
```

### 方式 B：定义时直接声明变量

```cpp
struct Student {
    char name[100];
    char id[10];
    short gender;
} s1;
```

### 方式 C：typedef 简化写法

```cpp
typedef struct Student {
    char name[100];
    char id[10];
    short gender;
} Stu;

Stu s1;
```

## 3. 联合体 union

- 联合体不同成员共享同一块内存。
- 也就是说：`l`、`c[8]`、`s` 这几个成员在内存中是同一段空间。
- 适合节省空间、存储不同类型但同一时刻只使用一种类型的数据。

```cpp
#include <iostream>
using namespace std;

union MyUnionType {
    unsigned long l;           // 8 字节
    unsigned char c[8];        // 8 字节
    struct {
        unsigned char i;        // 1 字节
        unsigned char o;        // 1 字节
        unsigned short v;       // 2 字节
    } s;
};

int main() {
    MyUnionType data1, data2, data3;

    data1.c[0] = 'a';
    data2.l = 0x3EUL;
    data3.s.i = 'f';

    cout << data1.c[0] << endl;
    cout << hex << data2.l << endl;
    cout << data3.s.i << endl;
    return 0;
}
```

### 关键点

- 联合体的大小由最大的成员决定。
- 赋值给 `data2.l` 后，`data2.c` 也会发生变化，因为它们共享内存。
- 所以不能把联合体当成“多个数据同时存在”的结构。

### 正确性说明

- 原代码中的 `data2.1 = 0x3EUL;` 是错误的，因为 `1` 不能作为成员访问符。
- 正确应为：`data2.l = 0x3EUL;`
- `MyUnionType` 拼写错误，应该是 `MyUnionType`。

## 4. 枚举 enum

- 枚举是一种符号化常量的方式。
- 它可以让代码更容易读、也更容易维护。

### 4.1 普通枚举

```cpp
#include <iostream>
using namespace std;

enum ColorType {
    Red,
    Blue,
    Yellow,
    Green
};

int main() {
    ColorType color = Red;

    if (color == Red) {
        cout << "Red" << endl;
    }

    return 0;
}
```

### 4.2 指定枚举值

```cpp
enum ColorType2 {
    Red2 = 1,
    Blue2,
    Yellow2,
    Green2
};
```

- `Red2 = 1` 之后后面的值会依次递增：`Blue2 = 2`，`Yellow2 = 3`，`Green2 = 4`。

### 4.3 作用域枚举 enum class

- `enum class` 具有作用域，避免命名冲突。
- 访问方式：`ColorType3::Red`。

```cpp
#include <iostream>
using namespace std;

enum class ColorType3 {
    Red,
    Blue,
    Yellow,
    Green
};

int main() {
    ColorType3 color = ColorType3::Red;

    if (color == ColorType3::Red) {
        cout << "Red" << endl;
    }

    return 0;
}
```

### 正确性说明

- 普通枚举 `enum ColorType { Red, Blue, ... };` 中，成员名在同一作用域下会直接暴露。
- `enum class` 会更安全，避免和其他枚举成员冲突。
- 原代码中 `enum class ColorType` 和前面的 `enum ColorType` 可能发生命名冲突，建议改为不同名称。

---

## 5. 总结

- 结构体：用于组合不同类型的数据，适合表示对象。
- 联合体：不同成员共享同一内存，适合节省空间。
- 枚举：用于定义一组命名常量，提高代码可读性。
