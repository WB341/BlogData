# C++ 关键知识点整理：override、final、static、const、this、friend

## 1. override

- `override` 是 C++11 引入的关键字。
- 它用于显式声明：这个函数是在重写基类的虚函数。
- 如果函数签名不匹配，编译器会直接报错，避免“看起来像重写，实际上没有重写”的问题。
- 作用：让代码更安全、更清晰。

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    virtual void show() {
        cout << "Base::show()" << endl;
    }
};

class Derived : public Base {
public:
    void show() override {   // 正确：重写 Base::show()
        cout << "Derived::show()" << endl;
    }
};
```

### 正确性说明

- `override` 只能用于重写虚函数。
- 如果基类中没有同名同参数的虚函数，编译器会报错。
- 这样可以避免误写导致的隐藏（hide）问题。

## 2. final

- `final` 表示“不能再被继承”或“不能再被重写”。
- 放在类名后面时，表示这个类不能再作为父类被继承。
- 放在虚函数后面时，表示这个函数不能再被子类重写。

```cpp
#include <iostream>
using namespace std;

class Base final {
public:
    virtual void print() final {   // 该函数不能再被子类重写
        cout << "Base" << endl;
    }
};

// class Child : public Base {}; // 错误：Base 已被 final 修饰，不能再继承
```

### 正确性说明

- `final` 不是为了“检测错误”，它是为了限制设计。
- `override` 是检查“是否真的重写了父类函数”。
- `final` 是限制“后续继续继承或重写”。

## 3. 静态成员 static

- `static` 修饰成员变量或成员函数时，属于类级别，不属于某个对象。
- 静态成员变量需要在类外进行定义和初始化。
- 静态成员函数不能直接访问非静态成员变量，必须通过对象来访问。
- 非静态成员函数可以直接访问静态成员。

```cpp
#include <iostream>
using namespace std;

class Demo {
public:
    void cheer() {
        cout << "非静态成员函数可以访问静态成员 count" << endl;
        count++;   // 合法
    }

    // 静态成员函数：可以直接通过类名调用
    static void hello() {
        count++;      // 合法：静态成员函数可以访问静态成员
        // a = 2;     // 错误：不能直接访问非静态成员 a
    }

private:
    static unsigned int count;  // 声明静态成员变量
    int a;                      // 非静态成员变量
};

unsigned int Demo::count = 0;  // 在类外初始化静态成员变量

int main() {
    Demo demo;
    demo.cheer();
    Demo::hello();

    // demo.count++;  // 错误：count 是私有成员，不能在类外直接访问
    // demo.a = 2;    // 合法：因为 a 是非静态成员，可以通过对象访问

    return 0;
}
```

### 正确性说明

- 原代码中存在几个明显问题：
  1. `a` 没有声明，`hello()` 中写 `a = 2;` 是错误。
  2. `Demo::count` 是私有成员，不能直接访问。
  3. 函数 `mian()` 拼写错误，正确应为 `main()`。
  4. `Domo` 拼写错误，应该是 `Demo`。

## 4. 单例模式

- 单例模式保证一个类在程序中只有一个对象实例。
- 常见实现方式：私有构造函数 + 静态实例 + 全局访问接口。

```cpp
#include <iostream>
using namespace std;

class Singleton {
private:
    static Singleton* instance;   // 静态实例指针

    // 私有构造函数：禁止外部直接创建对象
    Singleton() {
        cout << "Singleton created" << endl;
    }

public:
    static Singleton* getInstance() {
        if (instance == nullptr) {
            instance = new Singleton();
        }
        return instance;
    }

    void show() {
        cout << "单例对象正在工作" << endl;
    }
};

Singleton* Singleton::instance = nullptr;

int main() {
    Singleton* s1 = Singleton::getInstance();
    Singleton* s2 = Singleton::getInstance();

    cout << (s1 == s2 ? "同一个对象" : "不同对象") << endl;
    s1->show();

    return 0;
}
```

### 说明

- 这种模式在项目中常用于日志器、配置管理器等场景。
- 重点是保证全局唯一实例。

## 5. const 成员变量和 const 成员函数

### 5.1 const 成员变量

- `const` 修饰成员变量后，这个成员变量一旦初始化就不能修改。
- 常见写法：

```cpp
class Example {
private:
    const int value;   // const 成员变量，必须在初始化列表中赋值

public:
    Example(int v) : value(v) {}

    void print() const {
        cout << value << endl;
    }
};
```

### 5.2 const 成员函数

- `const` 成员函数表示：这个函数不会修改对象状态。
- 规则：`const` 成员函数中不能修改非静态成员变量，除非成员变量声明为 `mutable`。

```cpp
#include <iostream>
using namespace std;

class ConstExample {
private:
    int m_a;

public:
    ConstExample(int a) : m_a(a) {}

    int calculate(int x, int y) const {
        // m_a++;   // 错误：const 成员函数不能修改对象成员
        return x + y;
    }
};
```

### 正确性说明

- 原代码中的 `m_a++` 是错误的，因为 `calculate()` 是 const 成员函数。
- `const` 成员函数只能读取对象状态，不能修改成员变量。

## 6. this 指针

- `this` 指针指向当前对象自身。
- 在成员函数中，`this` 可以用来区分参数和成员变量。
- `return *this;` 常用于链式调用。

```cpp
#include <iostream>
using namespace std;

class Complex {
private:
    float r;
    float i;

public:
    Complex(float real, float imag) : r(real), i(imag) {}

    Complex& add(const Complex& other) {
        this->r += other.r;
        this->i += other.i;
        return *this;
    }

    void print() const {
        cout << r << "+" << i << "i" << endl;
    }
};

int main() {
    Complex a(1.0, 2.0), b(2.3, -2.0), c(1.1, 1.3);
    a.add(b).add(c);  // 链式调用
    a.print();
    return 0;
}
```

### 正确性说明

- 原代码中：
  - `complex` 应该是 `Complex`，首字母大写。
  - `foat` 应该是 `float`。
  - `end1` 应该是 `endl`。
  - 构造函数和成员函数中缺少 `std::` 或 `using namespace std;` 需要注意。

## 7. 友元 friend

- `friend` 关键字用于让某个函数或类访问本类的私有成员。
- 友元破坏了一部分封装性，因此要适度使用。

### 7.1 友元类

```cpp
#include <iostream>
using namespace std;

class A {
private:
    int m_value;

public:
    A() : m_value(10) {}

    friend class B;   // 声明 B 是 A 的友元类
};

class B {
public:
    int inc(A& obj) {
        obj.m_value += 5;  // B 可以访问 A 的私有成员
        return obj.m_value;
    }
};
```

### 7.2 友元函数

```cpp
#include <iostream>
using namespace std;

class A {
private:
    int m_value;

public:
    A() : m_value(10) {}

    friend int increase(A& obj);  // 声明友元函数
};

int increase(A& obj) {
    obj.m_value += 5;
    return obj.m_value;
}
```


## 8. 总结

- `override`：用于检查是否正确重写虚函数。
- `final`：用于禁止继续重写或继续继承。
- `static`：属于类而不是对象。
- `const`：保证对象状态不被修改。
- `this`：指向当前对象，常用于成员访问和链式调用。
- `friend`：允许特定函数/类访问私有成员，但要谨慎使用。
