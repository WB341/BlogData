# const成员变量 
不能修改成员变量
const成员函数不能调用非const成员函数
```cpp
class ConstExmaple{
    private:
    int m_a;
    public:
       int calculate(int a,int b) const     
};

int ConstExmaple::calculate(int a,int b) const{
    m_a++;//修改了成员变量，错误
    return a+b;
}
```
