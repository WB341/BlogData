# 运算符的重载（面向初学者）

## 1. 什么是运算符重载

- C++ 中，内置类型（如 `int`、`double`）本来就支持很多运算符，比如 `+`、`-`、`<<`。
- 但自定义类型（比如 `Complex`、`vector`）不能直接使用这些运算符。
- 通过“运算符重载”，我们可以让对象像内置类型一样使用这些符号。
- 关键字：`operator`
- 其主要作用：让自定义类型支持类似内置类型的运算语法。

### 语法形式

```cpp
返回类型 operator运算符(参数列表)
```

例如：

```cpp
Complex operator+(const Complex& other) const;
```

表示：定义一个 `+` 运算符，让两个 `Complex` 对象可以相加。

---

## 2. 第一个例子：重载 `+` 运算符

下面这个例子演示了如何让自定义类支持 `a + b` 这种运算。

```cpp
#include <iostream>
using namespace std;

// 1. 定义一个复数类：它包含实部和虚部
class Complex {
private:
    double real;   // 复数的实部
    double imag;   // 复数的虚部

public:
    // 2. 构造函数：用于创建对象
    // 这里使用了初始化列表，效率更高，也更符合 C++ 习惯
    Complex(double r = 0.0, double i = 0.0) : real(r), imag(i) {}

    // 3. 重载 + 运算符
    // 关键字：operator 表示“重载运算符”
    // 关键字：const 表示这个函数不会修改当前对象
    Complex operator+(const Complex& other) const {
        // 4. 返回一个新对象，表示两个复数相加的结果
        return Complex(real + other.real, imag + other.imag);
    }

    // 5. 输出函数：方便查看结果
    void print() const {
        cout << real << " + " << imag << "i" << endl;
    }
};

int main() {
    Complex a(0.1, 2.0);  // 创建对象 a
    Complex b(0.4, -2.1); // 创建对象 b
    Complex c = a + b;     // 这里使用了重载后的 +
    c.print();              // 输出 c

    return 0;
}
```

### 解释

- `Complex operator+(const Complex& other) const`：表示“重载 `+` 运算符”。
- `const Complex& other`：表示输入参数是一个常量引用，避免拷贝，且不修改它。
- `const`：表示这个成员函数不会修改对象自身状态。
- `return Complex(...)`：返回一个新的对象，作为相加后的结果。

### 关键点：为什么这样写

- `a + b` 原本对自定义对象是不合法的。
- 通过重载 `+`，编译器知道如何把两个 `Complex` 相加。
- 这让代码更自然，也更接近数学表达式。

## 3. 重载输出流 `<<`

### 3.1 为什么要重载 `<<`

`cout << 123` 能输出数字，是因为 `<<` 对 `int` 已经被定义好了。

但如果我们有自定义对象，比如 `vector<int>`，通常想写：

```cpp
cout << numbers << endl;
```

那么就需要重载 `<<` 运算符。

### 3.2 正确写法

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 1. 重载输出流 <<
// 关键字：ostream 表示输出流对象，通常是 cout
// 关键字：operator<< 表示我们要定义 << 操作
ostream& operator<<(ostream& out, const vector<int>& numbers) {
    out << "[";  // 先输出左中括号

    // 2. 遍历整个 vector
    for (size_t i = 0; i < numbers.size(); ++i) {
        if (i != 0) {
            out << ", ";   // 不是第一个元素时，输出逗号和空格
        }
        out << numbers[i]; // 输出当前元素
    }

    out << "]";  // 输出右中括号
    return out;   // 返回输出流，方便连续输出：cout << a << b
}

int main() {
    vector<int> numbers{1, 3, 5, 7, 9}; // 创建 vector
    cout << numbers << endl;             // 调用 operator<<(cout, numbers)

    return 0;
}
```

### 3.3 这段代码的关键点

- `ostream&`：返回输出流对象的引用，目的是支持连续输出。
- `const vector<int>& numbers`：不想拷贝整个 vector，直接按引用读取。
- `return out;`：让 `cout << numbers << endl;` 能正常写成链式输出。
- `operator<<(cout, numbers)`：编译器实际上把 `cout << numbers` 解释成这个函数调用。

### 3.4 常见错误说明

原始版本中有很多明显问题：

```cpp
count << "hello,world";
```

这是错误的，因为 `count` 应该是 `cout`。

```cpp
unsignde int last=numders.size()-1;
```

这里有拼写错误：

- `unsignde` 应该是 `unsigned`
- `numders` 应该是 `numbers`

```cpp
return 0;
```

在输出流重载函数中，应该返回 `out`，不能返回 `0`，因为输出流需要继续使用。

## 4. 函数调用运算符 `()`

### 4.1 这是什么

当一个对象像函数一样被调用时，就需要重载函数调用运算符 `()`。

语法：

```cpp
返回类型 operator()(参数列表)
```

### 4.2 例子：表示一次函数关系

```cpp
#include <iostream>
using namespace std;

// 1. 这个类表示一条直线：y = K * x + b
struct LinearFunction {
    double K;  // 斜率
    double b;  // 截距

    // 2. 重载 () 运算符
    // 关键字：operator() 表示“让对象像函数一样调用”
    double operator()(double x) const {
        return K * x + b;  // 计算 y
    }
};

int main() {
    LinearFunction f{1.5, 3.0}; // 创建一个函数对象

    cout << "f(0) = " << f(0) << endl; // 这里 f(0) 就像调用函数一样
    cout << "f(3) = " << f(3) << endl;

    return 0;
}
```

### 4.3 关键点

- `f(0)` 的意思是：把 `0` 当作参数传给 `operator()`。
- 这类对象通常叫“函数对象”（functor）。
- 它非常适合放进算法中，像一个可复用的函数。

### 4.4 初学者理解方式

你可以把它想成：

```cpp
obj(arg)
```

等价于：

```cpp
obj.operator()(arg)
```

## 5. 间接引用运算符 `->`

### 5.1 这是什么

`->` 通常用于指针访问对象成员：

```cpp
p->name
```

重载 `->` 后，可以让自定义对象像指针一样使用。

### 5.2 例子：封装一个指针

```cpp
#include <iostream>
using namespace std;

struct Complex {
    double r;  // 实部
    double i;  // 虚部
};

class LocalPtr {
private:
    Complex* ptr; // 指向真实对象的指针

public:
    // 1. 构造函数：接收一个 Complex 指针
    explicit LocalPtr(Complex* p = nullptr) : ptr(p) {}

    // 2. 重载 -> 运算符
    // 关键字：operator-> 表示让对象像指针一样访问成员
    Complex* operator->() {
        return ptr;
    }

    // 3. 析构函数：释放资源
    ~LocalPtr() {
        delete ptr;
    }

    // 4. 禁止拷贝和赋值，避免多次释放同一块内存
    LocalPtr(const LocalPtr&) = delete;
    LocalPtr& operator=(const LocalPtr&) = delete;
};

int main() {
    LocalPtr pComplex(new Complex{0.1, 0.5});
    pComplex->i += 1.0;  // 等价于：(*pComplex).i += 1.0
    cout << pComplex->r << " + " << pComplex->i << "i" << endl;

    return 0;
}
```

### 5.3 关键点

- `pComplex->i` 的含义：访问 `pComplex` 内部保存的 `Complex` 对象的成员 `i`。
- 这样做可以让对象更像“智能指针”。
- `operator->()` 一般返回一个指针或指针的引用。

### 5.4 常见错误说明

```cpp
pComplex1->i++;
```

这里 `pComplex1` 是变量名拼写错误，应该是 `pComplex`。

另外：

```cpp
if (m_ptr) delete m_ptr;
```

这行代码是合理的，但最好确保对象生命周期清晰，避免重复释放。

## 6. 下标运算符 `[]`

### 6.1 作用

`[]` 让对象像数组一样访问元素。

例如：

```cpp
arr[0]
```

如果你定义了自己的容器类，也可以重载 `[]`。

### 6.2 例子：自定义数组

```cpp
#include <iostream>
using namespace std;

class MyArray {
private:
    int data[5]; // 内部存储 5 个 int

public:
    // 1. 构造函数：初始化数组
    MyArray() {
        for (int i = 0; i < 5; ++i) {
            data[i] = i * 10;
        }
    }

    // 2. 重载 []
    // 关键字：operator[] 表示可以使用 arr[i] 这样的语法
    int& operator[](int index) {
        return data[index];
    }

    // 3. 只读访问版本（可选）
    const int& operator[](int index) const {
        return data[index];
    }
};

int main() {
    MyArray arr;
    arr[2] = 99; // 修改第 3 个元素
    cout << arr[2] << endl;

    return 0;
}
```

### 6.3 关键点

- `operator[]` 通常返回引用，所以可以被赋值。
- 这个特性让自定义容器的使用方式和原生数组非常相似。

## 7. 类型转换运算符

### 7.1 作用

有时我们希望一个自定义对象可以自动转换成某种基本类型，比如：

```cpp
int x = obj;
```

这就需要重载“类型转换运算符”。

语法：

```cpp
operator 类型名();
```

### 7.2 例子

```cpp
#include <iostream>
using namespace std;

class MyInt {
private:
    int value;

public:
    MyInt(int v = 0) : value(v) {}

    // 1. 类型转换运算符：把 MyInt 转成 int
    operator int() const {
        return value;
    }
};

int main() {
    MyInt a(42);
    int x = a;  // 自动转换为 int
    cout << x << endl;

    return 0;
}
```

### 7.3 关键点

- `operator int()` 让对象能隐式转换为 `int`。
- 这种转换有时很方便，但也容易让代码变得不够清晰。
- 所以使用时要注意：不要滥用隐式转换，否则容易引发歧义。

---

## 8. 不能重载的运算符

C++ 中，并不是所有运算符都能重载。以下这些不能重载：

- `.`：成员访问运算符
- `.*`：成员指针运算符
- `::`：作用域解析运算符
- `?:`：三元条件运算符
- `sizeof`：大小运算符
- `typeid`：类型信息运算符

### 8.1 重要说明

- 不能重载的运算符是语言本身规定的。
- 这些运算符具有特殊语法，重载后会破坏语言规则。

### 8.2 还有一个常见规则

- 如果两个操作数都只是基本类型（如 `int + int`），就不能自己重载它们。
- 运算符重载通常是为了让“自定义类型”能像“内置类型”一样工作。

---

## 9. 总结：运算符重载的本质

### 9.1 重点概念

- `operator`：重载运算符的关键字。
- `<<`：常用于输出流重载。
- `()`：让对象像函数一样被调用。
- `->`：让对象像指针一样访问成员。
- `[]`：让对象像数组一样访问元素。
- `operator 类型()`：实现类型转换。

### 9.2 初学者理解一句话

“运算符重载，就是让对象可以像内置类型一样使用各种运算符。”

比如：

```cpp
Complex a, b, c;
c = a + b;      // 常见的数学表达式
cout << c;      // 输出对象
arr[0] = 10;    // 像数组一样访问
f(3);           // 像函数一样调用
```

这些语法都依赖于运算符重载。

## 10. 代码检查结论

原始笔记里有不少错误，主要集中在以下几个方面：

1. `count` 应该是 `cout`。
2. `operator<<` 返回值应返回输出流对象，而不是 `0`。
3. 变量名拼写错误：`numders`、`unsignde`、`pComplex1`、`Compelex` 等。
4. `a = a << 3` 只是位运算，不是运算符重载例子。
5. `Complex` 类中构造函数和成员函数需保证语法正确，不能随意拼写。
6. `operator->()` 需要返回指针，且适合作为“智能指针”封装。

修正后的版本更适合初学者学习，因为它不仅保留了核心知识，还补充了关键字作用、使用场景和常见错误。

## 11. 补充：常见面试/考试问题

### 题目 1：什么是运算符重载？

答：运算符重载允许我们为自定义类型重新定义运算符的行为，使其像内置类型一样使用。

### 题目 2：重载运算符时为什么通常写成成员函数或友元函数？

答：

- 成员函数适合面向对象的运算，例如 `a + b`。
- 友元函数适合需要访问私有成员并且操作数不一定是当前对象时，比如重载 `<<`。

### 题目 3：为什么不能重载 `.`、`::`、`?:`？

答：这些运算符有严格的语言语法和编译器语义，不能像普通运算符那样自定义。

### 题目 4：什么时候需要重载 `[]`？

答：当你自己写容器类时，想让它像数组一样访问元素时，就可以重载 `[]`。

### 题目 5：`const` 在重载成员函数中有什么作用？

答：它表示该函数不修改对象状态，便于调用常量对象，且表达语义更清晰。

## 12. 一句话复习

运算符重载的核心是：

- 让自定义类型支持类似内置类型的语法；
- 关键字是 `operator`；
- 关键字的主要作用是告诉编译器：这个函数负责处理某个运算符；
- 合理使用时，代码更自然、更易读；
- 但要注意不要滥用，避免产生歧义或不可维护代码。

以上内容可以作为一个初学者的入门笔记。
