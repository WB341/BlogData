# 类的继承

## 1. 访问控制权限

- `public`：类内部、派生类、外部都可以访问
- `protected`：类内部和派生类可以访问，外部不能直接访问
- `private`：只有本类内部可以访问，派生类和外部都不能直接访问

```cpp
#include <iostream>
#include <string>

using namespace std;

// 语法：class 派生类名 : public 基类名 {
// 这里表示 Circle 继承 Shape，并且继承方式为 public
class Shape {
protected:
    // positionX / positionY 是保护成员，子类可以访问
    int positionX;
    int positionY;

private:
    // shapeName 是私有成员，只有 Shape 自己能访问
    string shapeName;

public:
    // 这是一个公共成员变量，外部可以访问
    int publicNumber;

    // 这是一个公共函数，返回面积
    virtual float area() {
        return 0.0f;
    }

    // 设置图形名称
    void setName(string name) {
        shapeName = name;
    }

    // 绘制图形
    void draw() {
        cout << "我不知道怎么画" << endl;
    }
};

// 定义常量 PI，注意：这里是全局常量，适合做数学常量
const float PI = 3.1415926f;

class Circle : public Shape {
private:
    float radius;

public:
    // 构造函数：初始化半径，位置默认设为 0
    // 注意：positionX 和 positionY 是基类的 protected 成员，
    // 不能在派生类的成员初始化列表中直接这样初始化，
    // 必须在构造函数体中赋值或通过基类构造函数初始化。
    Circle(float r = 0.0f) : radius(r) {
        positionX = 0;
        positionY = 0;
    }

    // 重写父类 draw()，子类可以扩展自己的绘制逻辑
    void draw() {
        cout << "半径为：" << radius << endl;
        cout << "圆心为(" << positionX << ", " << positionY << ")" << endl;
        cout << "publicNumber = " << publicNumber << endl;
    }

    // 重写父类 area()，圆面积 = PI * r^2
    float area() override {
        return PI * radius * radius;
    }
};
```

### 代码正确性说明

1. `class派生类名称：public基类名称{}` 这种写法在 C++ 中是错误的，应该写成：
   `class Circle : public Shape {}`
2. `publicNumber;` 是一个成员声明，但没有类型，必须明确声明为 `int publicNumber;`
3. `shapeName` 是私有成员，不能在 `Circle` 中直接访问；只能通过 `setName()` 这类公开方法访问
4. `positionX` 和 `positionY` 是 `protected`，所以 `Circle` 可以访问
5. 代码中原来 `positionX` 被输出了两次，应改为 `positionX` 和 `positionY`
6. `draw()` 函数中的输出顺序最好保持清晰，方便观察

## 2. 不能被继承的成员

以下成员不能被继承：

- 构造函数
- 析构函数
- 赋值运算符 `=` 相关实现
- 类的友元

原因：这些成员更偏向“对象的构造、销毁与特殊权限控制”，并不属于“继承层次中的可复用内容”。

## 3. 函数重写与多态示例

```cpp
#include <iostream>
using namespace std;

class BaseClass {
public:
    // 如果要实现多态，基类函数必须声明为 virtual
    virtual void greet() {
        cout << "这是基类" << endl;
    }
};

class SubClass : public BaseClass {
public:
    // 重写基类虚函数
    void greet() override {
        cout << "这是子类" << endl;
    }
};

int main() {
    SubClass obj;

    // 基类指针指向子类对象
    BaseClass* pBase = &obj;

    // 基类引用绑定到子类对象
    BaseClass& refBase = obj;

    obj.greet();        // 直接调用子类版本
    pBase->greet();     // 通过基类指针调用子类版本（多态）
    refBase.greet();    // 通过基类引用调用子类版本（多态）

    return 0;
}
```

### 这段代码的关键点

1. `virtual` 让基类方法具备多态能力
2. `override` 可以明确告诉编译器：这是重写父类虚函数
3. `SubClass obj; BaseClass* pBase = &obj;` 这种写法是典型的多态应用
4. 如果没有 `virtual`，那么 `pBase->greet()` 会调用 `BaseClass::greet()`，不会表现出多态

---

## 4. 总结

- 继承的本质：复用已有代码，并扩展新的功能
- 访问权限控制：保证数据封装和安全性
- 虚函数 + 重写：实现多态
- 重写时需要遵循函数签名一致，通常加 `override` 提高可读性和安全性
